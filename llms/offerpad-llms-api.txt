# Offerpad — API surface

> Offerpad Solutions Inc. (NYSE: OPAD) is a US iBuyer and licensed residential real estate
> brokerage in seventeen states. It buys homes for cash, renovates and resells them, lists homes
> as a brokerage, and runs a Renovate service. Offerpad publishes NO developer portal, NO API
> documentation and NO self-serve API access. This file describes the API surface that actually
> exists, verified by probe on 2026-07-26.

Generated by API Evangelist from the artifacts in this repository. Offerpad's own llms.txt
(https://www.offerpad.com/llms.txt, saved verbatim at llms/offerpad-llms.txt) is a Yoast SEO
marketing file and contains no API information.

## What is callable

- [Offerpad WordPress REST API](https://www.offerpad.com/wp-json/): the stock WordPress REST API of the marketing site. 411 routes across 20 namespaces, anonymously readable, application passwords for writes. A content-management surface — NOT a real estate, listing, valuation or transaction API.
- [Derived OpenAPI (wp/v2)](openapi/offerpad-wordpress-wp-v2-openapi.yml): 128 paths, 227 operations, derived by API Evangelist from the live route discovery document. Offerpad publishes no OpenAPI.
- [Route discovery document](openapi/offerpad-wp-json-discovery.json): the raw /wp-json/ index, saved verbatim.

## What exists but is closed

- Offerpad Helix backend (https://helix.offerpad.com): the private customer/transaction backend behind Offerpad Connect. Undocumented, no public client registration. Observed paths in [helix/offerpad-helix-observed-endpoints.yml](helix/offerpad-helix-observed-endpoints.yml).
- Offerpad identity (https://offerpad.okta.com/oauth2/ausftur6n2aTu6Sur357): Okta authorization server. OIDC discovery and RFC 8414 metadata are anonymous; tokens are not obtainable by third parties.
- Partner programmes — Direct+, Powered By Offerpad, homebuilder services, vendor network: web intake forms behind an NDA, no programmatic interface.

## What does not exist

- No developer portal, no API reference, no getting-started guide, no SDK, no CLI, no Postman collection.
- No webhooks, no events, no AsyncAPI, no GraphQL, no gRPC.
- No status page, no changelog, no deprecation policy, no SLA, no security.txt, no trust center, no bug bounty.
- No RESO Web API or Data Dictionary certification, no OData service document, no UPI support.
- No sandbox, no test credentials, no rate-limit documentation.
